# ML feasibility: can Dot features alone tell the obstacle?

_Generated by `Analysis/ML/python/crossing_ml.py` on 2026-10-30 16:10._

## Setup

- **Rows:** obstacle crossings with `include_ml` = 1: 260 rows from 10 participants (H1/H2/H3 = 88, 90, 82; W1/W2 = 127, 133).
- **Inputs:** the 110 Dot FEATURE columns (thigh/shank/foot angles and angular velocity, foot acceleration, ZHC foot trajectory, spatiotemporal). No labels, camera, timing/block or flag columns; toe height left out (provisional).
- **Test:** leave-one-participant-out: train on 9, test on the unseen 10th, 10 times. Imputation (median), scaling, feature selection and the model are fitted on the 9 training participants only.
- **Main model:** L2 logistic regression, C = 0.1 fixed in advance. Check: random forest (500 trees).
- **Calibrated features:** minus the participant's own level-walk median; lengths in mm divided by leg length. Raw = the dataset values.
- **Significance:** permutation test, labels shuffled within each participant (1000 permutations for all / lead / trail, 300 for the feature groups); p = (1 + #null >= observed) / (1 + n).
- **Caveat:** lead/trail roles and the crossing stride come from the camera (Dot-only detection agreed on all matched crossings, 90% found), so the model assumes the crossing is already located.
