## 2. End to end: detect -> pair (lead = first foot) -> height

**Reading.** With no camera, the Dot foot sensors alone find almost every obstacle crossing, tell which foot led, and recognise the obstacle height for most crossings of a person they were never trained on - provided the device scales the features to the person's own crossings (a few minutes of use). Scaled to ordinary walking only, height drops to near the generic level, the same person-specific bottleneck seen everywhere else.
