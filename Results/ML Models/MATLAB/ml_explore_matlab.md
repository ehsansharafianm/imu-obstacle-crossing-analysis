_Generated by `Analysis/ML/crossing_ml_explore.m` on 2026-10-31 08:02._

Same data and rules as `ml_report_matlab.md`: 260 obstacle crossings, 10 participants, every result on a participant the model never saw (leave-one-participant-out; all fitting on the other 9). Height H1/H2/H3 (chance 33%), width W1/W2 (chance 50%). Cells = balanced accuracy (95% participant-bootstrap CI) and the worst participant. **level** = minus own level-walk median, lengths / leg length (generic: a device needs only a short normal walk); **self** = each person scaled to their own median / IQR over their crossings (needs ~10-15 unlabelled mixed crossings).

## X3. Within-person ranking (generic model + ranking, no person normalization)

The generic (level-normalized) model gives each crossing an expected height score (sum P x 10/20/30). Each person's crossings are then ranked and split into thirds (lowest third = H1, ...). No labels are used, but it assumes the person crossed roughly equal numbers of each height, which the protocol guarantees here (optimistic for real-world use).

## What worked (summary)

| idea | before | after | comment |
|---|---|---|---|
| clearance-shape features, generic model (lead, level, logistic) | 62.1% | **72.8%** (p 0.003) | 13 features beat the 57 summary features without any person calibration |
| honest nested selection, generic settings only | 62.1% | **69.4%** (58-80) | best generic setting chosen fairly |
| + ranking each person's crossings into thirds | 62.1% | **87.0%** | shape, fusion; assumes a mix of heights |
| 1 labelled crossing per height from the new person | 71.8% (summary) | **80.6%** (shape) | 3 crossings of calibration |
| best single setting with self normalization | - | 90.4% | summary, fusion, forest |
| best model / ensemble with self normalization | - | 91.5% | ensemble (8 models), fusion, soft vote |
| honest nested selection, all settings | 89.3% (Part 4.1) | **91.5%** (86-97) | worst participant 73% |
| self-training on the new person | 72.8% (shape) | 54.0-67.1% | did not help (the model reinforces its own errors) |
| width, best new idea | 64.3% | 66.2% | ratio + summary, fusion, logreg - width stays weak |

**Caveats.** The shape features were designed after looking at the first results (a few iterations, guided by biomechanics), so a small optimism remains even under nested selection; confirm on new participants. The ranking and self normalization assume the person's crossings cover several heights. Using the order of crossings (the obstacles came in blocks of 5) would raise accuracy further but would be cheating, so it was not used.
